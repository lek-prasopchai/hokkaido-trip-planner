# เอกสารออกแบบ: Hokkaido Trip Planner v2

สถานะ: ทำแล้ว (7 พ.ย. 2026) — ส่วนที่ต่างจากร่าง: ชื่อสถานที่เก็บเป็น name (ไทย) + en + ja แทน name:{th,en,ja}; ร้านอาหาร 39 ร้าน (ไม่ถึง 80–100); สถานที่ 239; ยังไม่มี MAPCODE/เบอร์โทร; ไม่มี QR ในการ์ดแอป

## 1. เป้าหมาย

เว็บวางแผนเที่ยวฮอกไกโดแบบเที่ยวเอง ใช้กันเองไม่กี่คน เปิดบนมือถือได้ทั้งก่อนบินและระหว่างทริป

| ลำดับ | ส่วน | บทบาท |
|---|---|---|
| หลัก | จัดทริป (ภาพรวม + รายวัน) | ยืดหยุ่น คุมเวลาได้เอง ตรวจความเสี่ยงให้อัตโนมัติ |
| รอง | เตรียมของ + ไทม์ไลน์ก่อนบิน | ครบทุกหมวด ปรับตามแผนอัตโนมัติ |
| เสริม | สถานที่ ร้านอาหาร คู่มือ แอป ฉุกเฉิน งบ | ข้อมูลประกอบการตัดสินใจ |

ขอบเขตที่ตกลงแล้ว
- ตัววางแผนเน้น**หน้าหนาว** (ธ.ค.–มี.ค.) แต่**ฐานข้อมูลสถานที่ครบทุกฤดู** มีป้ายฤดูต่อที่
- รถยนต์และรถสาธารณะสำคัญเท่ากัน
- เว็บนิ่ง (static) บน GitHub Pages + PWA ไม่มี backend ไม่มี API เสียเงิน
- แชร์แผนด้วยลิงก์ (ดู/คัดลอกไปแก้ต่อ) ไม่มีแก้ไขพร้อมกัน
- เริ่มใหม่ ไม่ย้ายข้อมูลจาก localStorage เดิม
- ชื่อเฉพาะแสดง 3 ภาษา: ไทย / English / 日本語

นอกขอบเขต: บัญชีผู้ใช้, sync ข้ามเครื่องอัตโนมัติ, จองตั๋ว/ที่พักในเว็บ, ดึงรีวิว Google จริง, วางแผนครบ 4 ฤดู (ทำต่อได้ภายหลังเพราะข้อมูลฤดูมีแล้ว)

## 2. เทคนิค

- คง vanilla JS + Leaflet (มีใน `vendor/`) ไม่มี build step ไม่มี framework — โฮสต์บน GitHub Pages ได้ทันที
- เปลี่ยนจาก `file://` เป็นเปิดผ่าน http (ทดสอบในเครื่องด้วย XAMPP `http://localhost/hokkaido-trip-planner/`)
- PWA: `manifest.webmanifest` + `sw.js`
  - cache ทันที: โค้ด, CSS, `data/*.js`, รูปหลักของสถานที่ (รูปที่ 1)
  - cache เมื่อเปิดดู: รูปที่ 2–3, tile แผนที่ (จำกัดจำนวน)
  - ปุ่ม "ดาวน์โหลดไว้ใช้ออฟไลน์" ในตั้งค่า = โหลดรูปทั้งหมด + tile ตามพื้นที่ในแผน
- แผนที่: เพิ่ม OpenStreetMap เป็นตัวเลือก (เดิมใช้ไม่ได้เพราะ `file://`) คง Esri/GSI ไว้
- เส้นทางขับรถ: คง OSRM + cache เดิม
- พยากรณ์อากาศ: Open-Meteo (ฟรี ไม่ต้องใช้ key) ล่วงหน้าได้ 16 วัน ถ้าเกินแสดงค่าเฉลี่ยรายเดือน (ข้อมูลนิ่งใน `data/climate.js`)
- อัตราแลกเงิน: ดึงจาก API ฟรี (เช่น open.er-api.com) วันละครั้ง กรอกเองทับได้
- แชร์ลิงก์: บีบ state ด้วย `CompressionStream("deflate-raw")` → base64url → ใส่ใน `#share=` ผู้รับกด "คัดลอกเป็นแผนของฉัน" ได้ ถ้าลิงก์ยาวเกินไปให้ส่งออก .json แทน (คงไว้)
- พิมพ์/PDF: คงไว้ ปรับ layout ใหม่

## 3. โครงหน้า (4 แท็บ)

มือถือ = แถบแท็บล่าง, จอใหญ่ = แถบข้าง

### แท็บ 1: ทริปของฉัน (หลัก)
1. **ตั้งค่าทริป** (wizard ครั้งแรก, แก้ทีหลังได้) — ดูข้อ 4
2. **ภาพรวม**
   - แถบเวลาทั้งทริป: แต่ละวันเป็นแถว แสดงช่วงเดินทาง/เที่ยว/กิน/มืด สีบอกระดับความแน่น
   - การ์ดสรุป: วัน/คืน, เวลาขับรวม, เวลานั่งรถไฟรวม, ค่าใช้จ่ายประมาณ, จำนวนคำเตือน
   - แผนที่ทั้งทริป + ที่พักแต่ละคืน
   - รายการคำเตือนทั้งหมด กดแล้วกระโดดไปวันนั้น
   - เลือกรูทสำเร็จรูป (คงระบบให้คะแนนรูทเดิม เพิ่มรูทสำหรับรถสาธารณะ)
3. **แผนรายวัน** — ดูข้อ 5
4. **ที่พัก** — รายการที่พักต่อคืน (ข้อ 4.3)
5. **โหมด "วันนี้"** (เปิดอัตโนมัติเมื่อวันที่อยู่ในช่วงทริป)
   - จุดถัดไป + ปุ่มนำทาง (Google Maps / ตารางรถ NAVITIME)
   - เวลาพระอาทิตย์ตก, อากาศวันนี้, รถเที่ยวสุดท้ายกลับที่พัก
   - ทำเครื่องหมาย "ไปแล้ว" / "ข้าม" แล้วคำนวณเวลาที่เหลือใหม่

### แท็บ 2: ค้นหา
- สถานที่ / ร้านอาหาร / เทศกาล ในหน้าเดียว สลับรายการ ↔ แผนที่
- ตัวกรอง: ภูมิภาค, ประเภท, ฤดู/เดือน (ค่าเริ่มต้น = ช่วงวันเดินทาง), ไปด้วยรถสาธารณะได้, ฟรี, เหมาะกับเด็ก, เปิดค่ำ
- เรียง: ความนิยม, ใกล้ที่พัก, ระยะจากจุดที่เลือก
- การ์ดสถานที่ → หน้ารายละเอียด (ข้อ 6.1) + ปุ่ม "ใส่วันที่ …"

### แท็บ 3: เตรียมตัว (รอง)
- ไทม์ไลน์ก่อนบิน (นับถอยหลังจากวันบิน) — คงข้อมูล `prep.js` ปรับตามโหมดเดินทาง
- ของที่ต้องเตรียม — ข้อ 7
- งบประมาณ — คงของเดิม ดึงค่าเข้า/ค่ารถไฟจากแผนอัตโนมัติ

### แท็บ 4: คู่มือ (เสริม)
รู้จักฮอกไกโด, การเดินทาง (รถเช่า/JR/บัส/พาส), ที่พักแต่ละฐาน, ใช้ชีวิตที่นั่น, ภาษาญี่ปุ่นที่ใช้บ่อย, แอปแนะนำ (ข้อ 8), ฉุกเฉิน

### ตั้งค่า (ไอคอนมุมขวาบน)
- ภาษาที่แสดง: ไทย / ไทย+EN / ไทย+日本語 / ทั้ง 3
- อัตราแลกเงิน: อัตโนมัติ / กรอกเอง
- ธีม: สว่าง / มืด / ตามเครื่อง, ขนาดตัวอักษร
- ค่าเริ่มต้นการวางแผน: เวลาเผื่อ (%), ขับสูงสุดต่อวัน, เวลาเริ่ม/จบวัน (ทับค่า pace)
- แผนที่พื้นฐาน, ดาวน์โหลดออฟไลน์, ล้างข้อมูล, วันที่อัปเดตข้อมูล
- ตัดออก: ฟิลด์ `trip.level` (ไม่มีโค้ดใช้)

## 4. ตั้งค่าทริปและเที่ยวบิน

### 4.1 เที่ยวบิน
```js
// ตัวอย่างรูปแบบข้อมูลเท่านั้น เลขเที่ยวบิน/เวลาไม่ใช่ตารางจริง
flights: [
  { dir: "out", no: "TG670", from: "BKK", depDate: "2027-01-14", depTime: "23:45",
    to: "CTS", arrDate: "2027-01-15", arrTime: "08:30" },
  { dir: "in", no: "TG671", from: "CTS", depDate: "2027-01-22", depTime: "10:30",
    to: "BKK", arrDate: "2027-01-22", arrTime: "16:00" },
  // ต่อเครื่องในประเทศ = เพิ่ม segment ได้ เช่น HND → CTS
]
```
- วันเที่ยว = วันที่เครื่องลงญี่ปุ่น ถึง วันที่เครื่องออกจากญี่ปุ่น คำนวณจำนวนคืนเอง (ไม่ต้องกรอก)
- เข้า/ออกคนละสนามบินได้ (CTS, HKD, AKJ, KUH, MMB, OBO + HND/NRT/KIX ถ้าต่อเครื่อง)
- กรอกเลขเที่ยวบินเป็นข้อความเฉยๆ (ไม่ดึงข้อมูลออนไลน์) + เวลาเป็นเวลาท้องถิ่น

### 4.2 เวลาเผื่อวันแรก/วันสุดท้าย (แก้ได้)
| ขั้น | ค่าเริ่มต้น |
|---|---|
| ลงเครื่อง → ออกจากสนามบิน (ตม. + กระเป๋า) | 75 นาที |
| รับรถเช่า (โหมดรถ) / ซื้อพาส-ซิม (โหมดสาธารณะ) | 45 / 30 นาที |
| วันแรก: เที่ยวเลย / เข้าที่พักพักผ่อน | ตามที่เลือก; ลงเครื่องก่อน 9:00 หลังไฟลต์ข้ามคืน แนะนำ "เบา" |
| ถึงสนามบินก่อนเครื่องออก (ระหว่างประเทศ / ในประเทศ) | 2.5 ชม. / 1 ชม. |
| คืนรถ + เติมน้ำมัน | 45 นาที |

- วันสุดท้ายแสดง checklist: เช็กเอาท์, เติมน้ำมันใกล้ร้านคืนรถ, คืนรถ, รถรับส่ง, tax-free/ของฝากในสนามบิน
- คำนวณย้อน: "ต้องออกจากที่พักไม่เกิน HH:MM"
- เตือน: เครื่องออกเช้า (วันสุดท้ายแทบไม่มีเวลา), ลงดึก (เกิน 20:00 ร้านเช่ารถอาจปิด), ข้ามวันวันที่ไฟลต์ข้ามคืน

### 4.3 ที่พัก
```js
stays: [{ id, hub, name, nameJa, address, lat, lng, checkIn: "15:00", checkOut: "10:00",
          from: "2027-01-15", to: "2027-01-17", ref: "เลขจอง", url, phone, parking: true, note }]
```
- ใส่ก่อนหรือหลังจัดแผนก็ได้ ถ้ายังไม่ใส่ใช้จุดกลางของฐาน (`HUBS`) เหมือนเดิม
- เวลาเช็คอินใช้ตรวจวันย้ายเมือง (ถึงก่อนเช็คอิน → แนะนำฝากกระเป๋า)

### 4.4 ข้อมูลทริปอื่น
ผู้ใหญ่/เด็ก (อายุ), คนขับ, โหมด (รถ / สาธารณะ / ผสมรายวัน), pace, ความสนใจ, พาสที่ถือ (ไม่มี / JR Hokkaido Rail Pass 5-7-10 วัน / HEP)

## 5. แผนรายวัน

### 5.1 โครงข้อมูล
```js
days: [{
  date, mode: "car" | "transit",
  start: null,            // ทับเวลาเริ่มของ pace ได้
  items: [{
    kind: "place" | "food" | "custom" | "rest",
    ref: 12,              // id สถานที่/ร้าน
    custom: { name, lat, lng, url },   // kind = custom (ปักหมุดเอง/วางลิงก์ Google Maps)
    at: "18:00",          // ล็อกเวลา (จองร้าน/รอบเรือ) ไม่ใส่ = ปล่อยให้คำนวณ
    dur: 1.5,             // ทับเวลาที่ใช้ (ชม.)
    note: "",
    status: null | "done" | "skip"   // โหมดวันนี้
  }],
  note: "", planB: ""     // แผนสำรองถ้าถนนปิด/พายุ
}]
```

### 5.2 การแก้ไข
- ลากเรียงลำดับ (มือถือ: ปุ่ม ↑↓ ด้วย) — เลิกเรียงอัตโนมัติแบบใกล้สุด แต่มีปุ่ม "เรียงเส้นทางให้สั้นสุด" (ไม่แตะจุดที่ล็อกเวลา)
- ล็อกเวลา, แก้เวลาที่ใช้, โน้ต, ลบ, ย้ายไปวันอื่น
- เพิ่มจาก: รายการแนะนำ (คงตัวให้คะแนนเดิม), ค้นหาชื่อ, ปักหมุดบนแผนที่, วางลิงก์ Google Maps
- ช่องมื้ออาหาร: ระบบเสนอช่องกลางวัน/เย็น แนะนำร้านใกล้ตำแหน่ง ณ เวลานั้น ผูกร้านได้
- จัดอัตโนมัติ: คงปุ่ม "เติมวันนี้" / "จัดใหม่ทั้งทริป" — ไม่แตะรายการที่ผู้ใช้เพิ่มเองหรือล็อกไว้
- ย้อนกลับ (undo) 20 ขั้น

### 5.3 การคำนวณเวลา (ต่อยอด `planner.js`)
- timeline: เวลาเริ่ม → เดินทาง → อยู่ → … → กลับที่พัก; จุดล็อกเวลาเป็นหมุด ถ้าไปไม่ทันเตือน "ไม่ทัน" ถ้าเหลือเวลาบอก "ว่าง X นาที"
- เวลาเผื่อ % (ตั้งค่า) คูณทุกช่วงเดินทาง; ตัวคูณหิมะ `WINTER` ใช้เฉพาะ ธ.ค.–มี.ค.
- รถสาธารณะ: เวลาเดินทาง + เวลารอเฉลี่ย (ครึ่งหนึ่งของความถี่) + เดินจากสถานี
- ตรวจเพิ่มจากของเดิม:
  - รถสาธารณะ: เลยรถเที่ยวสุดท้ายกลับที่พัก (`bad`), ระยะห่างรถ > 60 นาที (`warn`), สถานที่ไปได้แค่ทัวร์/แท็กซี่ → แนะนำทัวร์
  - ขับรถ: ช่วงไม่มีปั๊ม/ร้าน (ข้อมูล `ROADS`/`DRIVE_EDGES` เพิ่มฟิลด์ `noFuel`) → เตือนเติมก่อน; ปั๊มต่างจังหวัดปิดราว 19:00
  - จุดล็อกเวลาชนกัน, ถึงที่พักก่อนเวลาเช็คอิน (info), สถานที่ปิดฤดูนี้ (`bad`), รอบเข้าสุดท้าย
  - ของเดิมที่คงไว้: ขับเกินขีด, มืดก่อนข้ามช่องเขา, วันปิด, นอกช่วงเทศกาล, ถึงสนามบินไม่ทัน, เกิน 15 วัน, คาร์ซีทเด็ก, ปีใหม่

### 5.4 รูทสำเร็จรูป
คง 8 รูทเดิม เพิ่มรูทสำหรับรถสาธารณะ เช่น "ซัปโปโร + อาซาฮิคาวะ + บิเอะ ด้วย JR + บัสท่องเที่ยว", "ใต้ด้วย JR ถึงฮาโกดาเตะ", "ตะวันออกด้วย JR Senmo Line + ทัวร์"

- ลิงก์อัตโนมัติ (ไม่ต้องเก็บ): Google Maps รีวิว (ค้นด้วย `ja`), TikTok ค้นหา, YouTube ค้นหา, Google รูป

- รายการที่รู้แล้วว่าขาด (ต้องยืนยันตอนค้น): Hill of the Buddha, Jet Coaster Road, Shinei no Oka, Kanno Farm, Flower Land Kamifurano, Shirogane Blue Pond (มีแล้ว), Kaminoko-ike, Lake Onneto, Hokuryu Sunflower, Takinoue / Higashimokoto ชิบะซากุระ, Matsumae, Unkai Terrace, Shakotan Blue, ถนนแปะก๊วย ม.ฮอกไกโด, Otaru Aquarium, Sapporo Factory, Mitsui Outlet, SL Fuyu-no-Shitsugen-go, Ryuhyo Monogatari, Kiroro
- รูป: Wikimedia Commons เท่านั้น (เหมือนเดิม) ขยาย `tools/enrich_places.py`
- MAPCODE: ไม่มี API ฟรี ต้องค้นทีละที่จากเว็บ mapcode แล้วกรอก — ถ้าไม่มีใช้เบอร์โทรแทน (GPS รถเช่าค้นด้วยเบอร์ได้)

### 6.2 ร้านอาหาร (`data/food.js` ใหม่)
```js
{ id, name: { th, en, ja }, hub, area, lat, lng, cuisine: "ramen",
  signature: "มิโสะราเมน", price: [1000, 1500], hours: "11:00–21:00", closedDays: "พุธ",
  queue: "คิวยาวช่วงเที่ยง", reserve: false, pay: "cash",
  tags: ["halal", "veg", "kids", "late"], url, tabelog, imgs, checked }
```
- ต่อฐานที่พัก 3–6 ร้าน (~80–100 ร้าน) เน้นร้านดัง + อาหารประจำถิ่น (ราเมน, ซุปแกงกะหรี่, จิงกิสคัง, ซีฟู้ด, ขนม)
- รูป: Wikimedia ถ้ามี ไม่มีก็ใช้ไอคอนหมวด + ปุ่มดูรูปใน Google

### 6.3 การเดินทาง
- `transit.js`: เพิ่มฟิลด์ `first`, `last`, `fare`, บัสท่องเที่ยวตามฤดู, ลิงก์ตารางทางการ
- `drive.js` / `roads.js`: เพิ่ม `noFuel` (ช่วงไม่มีปั๊ม), `seasonClosed` (ช่องเขาปิดตามฤดู)
- เครื่องคิดพาส: เทียบ JR Hokkaido Rail Pass กับตั๋วแยกตามแผน (`JR_PASS` มีแล้ว ต้องเพิ่มค่าโดยสารต่อช่วง)

### 6.4 เทศกาล
คง `festivals.js` อัปเดตวันที่ 2027 และเพิ่มงานที่ขาด (เช่น Asahikawa Winter Festival ถ้ายังไม่มี)

### 6.5 สภาพอากาศ (`data/climate.js` ใหม่)

## 7. ของที่ต้องเตรียม

- คง 165 รายการ / 14 หมวด เพิ่ม:
  - **ยาห้ามนำเข้าญี่ปุ่น** (เช่น ยาที่มี pseudoephedrine) + ยาที่ต้องมีใบรับรอง — ต้องยืนยันกับเว็บกระทรวงสาธารณสุขญี่ปุ่นก่อนใส่
  - หมวดเด็กเล็ก, ผู้สูงอายุ, ขากลับ (tax-free, ของฝาก, น้ำหนักกระเป๋า, ของเหลว)
- แสดงตามแผนอัตโนมัติ: ฟิลด์ใหม่ `when` เช่น `{ mode: "car" }`, `{ tag: "snow" }`, `{ kids: true }` — ไม่เข้าเงื่อนไขก็ซ่อน (เปิดดูทั้งหมดได้)
- เพิ่มของเองได้ (มีแล้ว), จำนวนคูณตามคน/คนขับ (มีแล้ว)

## 10. การทดสอบ

- ขยาย `tools/selftest.js`: เวลาเผื่อเที่ยวบิน, ไฟลต์ข้ามคืน, จุดล็อกเวลา, รถเที่ยวสุดท้าย, ช่วงไม่มีปั๊ม, แชร์ลิงก์เข้ารหัส/ถอดรหัสกลับได้ตรง
- ตรวจข้อมูล: สคริปต์เช็กทุกสถานที่มี `name.th/en/ja`, พิกัดอยู่ในฮอกไกโด, `hub` มีจริง, รูปมีไฟล์
- เปิดจริงด้วย Playwright ที่ความกว้าง 390px และ 1280px + ทดสอบออฟไลน์ (ปิดเน็ตหลัง cache)

## 11. ความเสี่ยง

- ข้อมูลเวลาเปิด/รถเที่ยวสุดท้าย/ราคาเปลี่ยนบ่อย → ทุกที่มี `checked` และหน้าเว็บบอกให้ตรวจก่อนไป
- การค้นข้อมูล ~100 จุดใหม่ + ร้าน ~100 ร้านใช้เวลามากที่สุด ทำเป็นชุดตามภูมิภาค ให้ผู้ใช้ตรวจทีละชุด
- `tools/build_data.py` ห้ามรันซ้ำ (เขียนทับข้อมูลที่แก้มือ) — ช่วง 3 จะเขียนสคริปต์แปลงครั้งเดียวแยกต่างหาก
- รูปที่ cache ไว้ออฟไลน์อาจหนักหลายสิบ MB → ให้ผู้ใช้กดดาวน์โหลดเอง ไม่โหลดทั้งหมดอัตโนมัติ
