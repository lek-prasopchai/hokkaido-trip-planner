# Hokkaido Trip Planner: เว็บวางแผนเที่ยวฮอกไกโด (v2)

เว็บนิ่ง (HTML/JS ล้วน ไม่ต้อง build) วางแผนเที่ยวฮอกไกโดเอง ขับรถหรือรถไฟ/บัส จัดเวลารายวัน ตรวจความเสี่ยงหน้าหนาว เตรียมของ และงบประมาณ
ออกแบบตาม `docs/redesign-spec.md`

## เปิดใช้
- ในเครื่อง: เปิดผ่าน XAMPP `http://localhost/hokkaido-trip-planner/` (ต้องเปิดผ่าน http: `file://` ใช้แผนที่ OSM/แชร์ลิงก์/PWA ไม่ได้)
- ขึ้นเว็บ: อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages ได้ทันที ติดตั้งลงมือถือเป็นแอป (PWA) และใช้ออฟไลน์ได้หลังเปิดครั้งแรก
- บน localhost จะไม่ลง service worker (กันไฟล์เก่าค้าง): ใส่ `?sw=1` ถ้าจะทดสอบออฟไลน์
- แก้ไฟล์แล้วเว็บไม่อัปเดต: รัน `node tools/bump.js` (เปลี่ยน `?v=` ใน `index.html` และ `V` ใน `sw.js` พร้อมกัน และเตือนถ้ามีไฟล์ js ที่ยังไม่อยู่ในรายการออฟไลน์) แล้วรีเฟรช 2 ครั้ง

## โครงหน้า (4 แท็บ)
1. **ทริปของฉัน**: ภาพรวม + แถบเวลาทั้งทริป + แผนรายวัน (ลากเรียง/↑↓ ล็อกเวลา แก้เวลาที่ใช้ เลือกวิธีเดินทางแยกรายช่วง รถ/รถไฟ/แท็กซี่/เดิน โน้ต จุดของฉัน (แก้ชื่อ/พิกัดได้) มื้ออาหาร (รายการปกติ ย้าย/ลบ/เพิ่มเองได้) ปุ่ม + เพิ่ม (มื้อ/จุดของฉัน: ร้านอาหารใส่เองจาก Google Maps) เมนู ⋯ (สลับวัน/จัดวันนี้ใหม่) ช่องค้นหาสถานที่ ⇄ ย้ายวัน รายการ ♡ อยากไป จุดสำรอง "ถ้ามีเวลา" ย้อนกลับ) / ข้อมูลทริป + เที่ยวบิน + เวลาเผื่อ / ที่พัก + สรุปการจอง / โหมดวันนี้
2. **ค้นหา**: สถานที่ทุกฤดู (กรองฤดู/เดือน รถไฟไปได้ ฟรี) + กล่องเทศกาลหน้าหนาว หน้ารายละเอียด + ลิงก์รีวิว Google Maps/YouTube/TikTok (รวมคาเฟ่/ของหวานที่ตั้งใจไปแวะ)
3. **เตรียมตัว**: สิ่งที่ต้องทำก่อนบิน / ของจำเป็น (~30 อย่าง ติ๊กอย่างเดียว แสดงตามแผน: โหมดเดินทาง ฤดู เด็ก) / งบประมาณโดยประมาณ
4. **คู่มือ**: คู่มือฉบับย่อ (เฉพาะที่คนไทยไม่รู้: ขับบนหิมะ รถไฟ ใช้ชีวิต กฎ กรองตามทริป) / เอกสาร + การจอง + ฉุกเฉิน

⚙ ตั้งค่า: ภาษาชื่อสถานที่ (ค่าเริ่มต้น English ตัวหนา + ไทย) ธีมมืด ขนาดตัวอักษร เวลาเผื่อ ขีดเวลาขับ ระดับขับบนหิมะ ที่เที่ยวสูงสุดต่อวัน มื้ออัตโนมัติ อัตราแลกเงินอัตโนมัติ ส่งออก/นำเข้า .json พิมพ์
🔗 แชร์: ลิงก์บีบอัดทั้งแผน คนรับกด "คัดลอกเป็นแผนของฉัน" ได้ (ไม่ซิงก์กัน)

## โค้ด
- `js/icons.js` ไอคอนลายเส้น Lucide (ISC) ใช้ `I("ชื่อ")`: เพิ่มไอคอน: ใส่ชื่อใน `tools/build_icons.js` แล้วรัน `node tools/build_icons.js` (ห้ามใช้อีโมจิในหน้าเว็บ ยกเว้นข้อความใน <option>/confirm ที่ใส่ SVG ไม่ได้)
- `js/tools.js` เอกสารและการจอง (`S.docs`) เก็บในเครื่องเท่านั้น ไม่ติดไปกับลิงก์แชร์ • ตัดออกแล้ว (ใช้แอปอื่นดีกว่า): บันทึกค่าใช้จ่ายจริง แปลงเยน ส่งออก .ics ดาวน์โหลดรูปออฟไลน์ หน้าแอปแนะนำ เมนูร้านอาหาร (คาเฟ่ย้ายไปอยู่ในสถานที่ ร้าน `f…` ในแผนเก่าแปลงเป็นจุดของฉันอัตโนมัติ: `dropFoods` ใน core.js)
- `js/core.js` ตัวช่วย ระบบบันทึก (`hokkaido-planner-v2`) ระยะทาง ฤดู พระอาทิตย์ แชร์ลิงก์ อากาศ (Open-Meteo) อัตราแลกเงิน
- `js/planner.js` ตรรกะแผน: รายการรายวัน `day.items` (สถานที่ = ตัวเลข, จุดของฉัน = `c…`, มื้ออาหาร = `m…` (ไม่มีพิกัด, `near` = เวลาประมาณ) • วิธีเดินทางรายช่วง `it.m` / ช่วงไปที่พัก `day.hm` • `it.maybe` = จุดสำรองไม่นับเวลา • `plan.wish` = รายการอยากไปที่ยังไม่ลงวัน) จำลองเวลา ตรวจความเสี่ยง จัดอัตโนมัติ
- `js/view-*.js` แต่ละหน้า, `js/map.js` แผนที่, `js/app.js` แท็บ/ตั้งค่า/แชร์/PWA, `sw.js` ออฟไลน์
- ทดสอบตรรกะ: `node tools/selftest.js`

## ข้อมูล (`data/`)
- `places.js` 284 สถานที่ (รวมวัด/ศาลเจ้า/จุดชมวิว: `tools/v3_places_culture.py`, หมวดที่ขาด (ยังไม่มีรูป): `tools/v4_places_gaps.py`): ชื่อไทย/อังกฤษ/ญี่ปุ่น `months` (เดือนที่เปิด/น่าไป) `sn` (ไฮไลต์รายฤดู) `tr` (รถไฟ/บัส) `url`: เพิ่ม/เติมด้วย `tools/v2_places.py`
- `packing.js` ของจำเป็น (แก้ในไฟล์ได้เลย), `templates.js` รูทสำเร็จรูป (มีรูทรถไฟล้วน), `guide.js` / `sheet_content.js` เนื้อหาคู่มือ
- รูปทั้งหมดจาก Wikimedia Commons (ตรวจด้วยตา) ที่มาอยู่ในหน้าดูรูปใหญ่: ไม่เก็บรูป/รีวิวจาก Google เพราะติดลิขสิทธิ์และข้อตกลงการใช้งาน
